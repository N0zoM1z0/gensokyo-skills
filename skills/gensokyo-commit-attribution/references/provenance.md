# Provenance

## Source anchor

Git commit trailers are structured message lines commonly used to record sign-off, review, and other contribution metadata. `Assisted-by` is a project-defined trailer here; it is not an assertion of Git authorship or a Touhou canon term.

## Interpretive bridge

Gensokyo Skills makes character workflows visible as decision provenance. When a character method materially changes a committed result, a compact trailer preserves that useful lineage without turning the commit subject into role-play.

## Project-original operator

The evidence gate, canonical character-to-skill mapping, first-material-use ordering, and idempotent renderer are original conventions of this project. The attribution utility itself has no character mapping and must never attribute itself.
