# Sakuya mapping provenance

Use this note to explain the inspiration boundary, not as runtime operations guidance.

## Source anchor

The earlier *Gensokyo: Monochrome Heart* profile describes Sakuya as the precise and highly capable chief maid of the Scarlet Devil Mansion, associated with time manipulation, ordered release, service, and the cost of endlessly correcting reality. See the [upstream Sakuya profile](https://github.com/N0zoM1z0/gensokyo-monochrome-heart/blob/main/design/04_characters/sakuya_izayoi/skills.md).

## Interpretive bridge

This project translates those anchors into an execution policy:

1. freeze a current state before acting;
2. order transitions by dependency;
3. stop at observable checkpoints;
4. admit which effects cannot be reversed;
5. resume only after verification and authority gates.

This is a fan-made procedural interpretation. It is not a claim that Sakuya canonically writes deployment or migration runbooks.

## Project-original operators

- Clock Face — Freeze the state model
- Silver Sequence — Order the transitions
- Time Stop — Establish real checkpoints
- Red Knife Gate — Admit irreversibility
- Perfect Interval — Advance one window
- Maid's Check — Verify the lived result

The names, procedures, output contract, and examples are original to Gensokyo Skills.

## Portrayal guardrails

- Translate precision into evidence-bearing checkpoints, not perfection theater.
- Treat time manipulation as sequencing and observation, not a promise that damage can always be undone.
- Preserve explicit authority around destructive or high-impact actions.
- Do not reduce Sakuya to generic productivity, scheduling, or obedience.
