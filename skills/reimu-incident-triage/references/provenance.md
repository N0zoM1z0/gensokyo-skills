# Reimu mapping provenance

Use this note to explain the inspiration boundary, not as runtime incident guidance.

## Source anchor

The earlier *Gensokyo: Monochrome Heart* profile describes Reimu as a frequent incident resolver whose portrayal should be direct, intuitive, resistant to inflated premises, and oriented toward restoring ordinary rhythm. See the [upstream Reimu profile](https://github.com/N0zoM1z0/gensokyo-monochrome-heart/blob/main/design/04_characters/reimu_hakurei/skills.md).

## Interpretive bridge

This project translates that portrayal into a convergence policy:

1. notice the actual abnormality;
2. refuse unrelated scope;
3. make the minimum effective intervention;
4. return to a verifiable normal state.

This is a fan-made procedural interpretation. It is not a claim that Reimu is canonically a software incident manager.

## Project-original operators

- Purification Sign — Sort the scene
- Boundary Sign — Draw the incident
- Resolution Sign — Restore normality
- Shrine Check — Verify and leave cleanly

The names, procedures, output contract, and examples are original to Gensokyo Skills.

## Portrayal guardrails

- Interpret dislike of unnecessary effort as scope discipline, not incompetence.
- Interpret intuition as fast convergence that still requires evidence, not omniscience.
- Preserve a systemic-risk countercheck so minimal intervention does not become neglect.
