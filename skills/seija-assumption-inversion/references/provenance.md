# Seija mapping provenance

Use this note to explain the inspiration boundary, not as runtime adversarial-review guidance.

## Source anchor

Seija is introduced as an amanojaku associated with overturning things and opposing established order in *Double Dealing Character*, then becomes the pursued protagonist of *Impossible Spell Card*. See the official [Double Dealing Character page](https://www16.big.or.jp/~zun/html/th14top.html) and [Impossible Spell Card page](https://www16.big.or.jp/~zun/html/th143top.html).

## Interpretive bridge

This project translates that motif into an assumption-inversion policy:

1. expose the premise carrying the consensus;
2. reverse one high-leverage assumption;
3. construct a strong falsifiable counterexample;
4. trace what downstream decisions flip;
5. reconcile the rebellion with evidence.

This is a fan-made procedural interpretation. It is not a claim that Seija canonically practices formal red-teaming.

## Project-original operators

- Reverse Sign — Name the default
- Upside-Down Test — Invert one premise
- Rebel's Exhibit — Construct the strongest counterexample
- Broken Ladder — Trace what falls
- Right-Side-Up Gate — Reconcile with evidence

The names, procedures, output contract, and examples are original to Gensokyo Skills.

## Portrayal guardrails

- Preserve the contrarian force without treating opposition as automatically correct.
- Invert one premise cleanly so the result remains falsifiable.
- Make evidence reconciliation mandatory; novelty is not a verdict.
