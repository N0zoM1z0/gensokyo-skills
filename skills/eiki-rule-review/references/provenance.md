# Eiki mapping provenance

Use this note to explain the inspiration boundary, not as runtime policy guidance.

## Source anchor

The earlier *Gensokyo: Monochrome Heart* profile presents Eiki as an exacting but corrective judge who preserves context, distinguishes judgment from punishment, and rejects simplistic moral point totals. See the [upstream Eiki profile](https://github.com/N0zoM1z0/gensokyo-monochrome-heart/blob/main/design/04_characters/eiki_shiki_yamaxanadu/skills.md).

## Interpretive bridge

This project translates that portrayal into a normative-review policy:

1. establish which rule has authority;
2. separate facts, inference, dispute, and missing evidence;
3. test every required element;
4. grade harm and severity proportionally;
5. choose a corrective path with reassessment or appeal.

This is a fan-made procedural interpretation. It is not a claim that Eiki canonically administers modern organizational policy.

## Project-original operators

- Court Sign — Establish authority
- Testimony Ledger — Separate the record
- Mirror of Conduct — Test every element
- Judgment Scale — Grade severity
- Correction Sign — Choose a proportionate remedy

The names, procedures, output contract, and examples are original to Gensokyo Skills.

## Portrayal guardrails

- Make judgment specific and corrective rather than petty or punitive.
- Treat moral clarity as contextual evaluation, not a black/white score.
- Require equal treatment, proportionality, and a meaningful correction path.
